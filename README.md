# CompUse 01 — Computer-Use Architectures

A technical survey of production computer-use agent systems: Anthropic's Claude Computer Use (screenshot &rarr; action loop, `computer_20241022` tool), OpenAI Operator (CUA model, WebDriver bridge), Gemini Mariner (multimodal browser-control), action-schema trade-offs (pixel coordinates vs accessibility-tree vs CSS selectors), screenshot versus DOM versus a11y-tree perception layers, Docker/VM sandboxing patterns, and the OSWorld, WebVoyager and AgentBench evaluation benchmarks.
